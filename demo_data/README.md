# SafeShare demo files

All files are synthetic and dated around Sunday, 4 October 2026, matching the Oniro demo environment.

- `photos/`: 3 photos from today, 2 from yesterday, 1 from five days ago, and 1 older private photo.
- `notes/`: a note from today, one from yesterday, and one older private note.
- `pdfs/`: a PDF from today, one from yesterday, and one older private PDF.

This makes the Today, Yesterday, Weekend, custom-range, manual-selection, file-type tabs, locked-item, preview, EXIF, and natural-language period features easy to demonstrate.

Useful assistant requests:

- `photos from today`
- `notes from yesterday`
- `photos and PDFs from the weekend`
- `files from the last 5 days`
